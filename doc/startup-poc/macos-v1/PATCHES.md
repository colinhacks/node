# Startup patch digest

These are the [15 retained patches](patches/series) against Node revision `8af75451e9041cd6058080ad3d4a65546797b418`. All measurements below are from **macOS arm64 on an M1 Max**; Linux and Windows validation is incomplete.

- **Reading the numbers:** ratios are median paired **control/candidate process-lifetime** ratios, including exit cleanup. Higher is better; `1.01×` means about 1% less latency. Brackets contain 95% bootstrap confidence intervals; `n` is paired rounds per workload. “Eval” means an empty eval program.
- **Attribution:** these experiments used different historical controls, not successive removals from the final executable. Grouped measurements are labeled; the ratios cannot be added or multiplied into the combined result.
- **Combined result:** the [final 350-round comparison](evidence/current-overall-defensible-clean/report.json.gz) measured empty CJS/ESM/eval at **1.877–1.889×**, about 47% less latency, against the same-revision PGO/ThinLTO control. That control already includes those build optimizations. Neither 2× same-source startup nor Bun parity was reached.

| [01 — ThinLTO and PGO](patches/01-build-darwin-thinlto-pgo.patch) | Enables cross-file compiler optimization and optimization guided by recorded training workloads on macOS. | Separate build experiments: [ThinLTO](evidence/thin-lto-confirm/report.json.gz), eval **1.01535× [1.00746, 1.01990]**, n=200; [PGO](evidence/pgo-use-confirm/report.json.gz), eval **1.06598× [1.06142, 1.07065]**, n=250. | [02 — Private symbols](patches/02-build-darwin-private-symbols.patch) | Hides Node, Ada and Abseil implementation symbols and strips unreachable code, reducing dynamic-loader work. Explicit exports preserve public extension and debugger entry points. | Partial component evidence: [private dependencies](evidence/private-deps-ablation/report.json.gz), eval **1.04670× [1.03906, 1.05269]**, n=80; [dead stripping](evidence/deadstrip-confirmation/report.json.gz), eval **1.01086× [1.00544, 1.01724]**, n=200. | [03 — Native hash arithmetic](patches/03-deps-rapidhash-native128.patch) | Uses native 128-bit multiplication for the modular arithmetic that generates V8's hash secrets, replacing a bit-at-a-time loop. | [Hash-only ablation](evidence/hash-ablation/report.json.gz), eval **1.09290× [1.06906, 1.11967]**, n=60, on top of the contemporary visibility control. | Compilers with native 128-bit integers; portable fallback retained elsewhere. V8/Rapidhash dependency change requiring exact arithmetic and generated-secret equivalence. |
| [04 — Borrowed help strings](patches/04-src-option-help-views.patch) | Avoids allocating a string for every CLI option description by borrowing immutable text. Future option registrations must use help text with static lifetime; temporary strings would dangle. |
| [05 — Earlier deadlock policy](patches/05-src-earlier-abseil-policy.patch) | Moves Node's existing disabling of Abseil deadlock detection before V8 setup allocates an unused tracking graph. | [Confirmation](evidence/deadlock-policy-confirm/report.json.gz), eval **1.00755× [1.00403, 1.01226]**, n=400. | Platform-independent initialization change. Must preserve embedder initialization flags, OpenSSL seeding/error paths and extra-CA ordering. Does not introduce a new policy of disabling detection. |
| [06 — Snapshot copy dispatch](patches/06-deps-v8-fixed-raw-dispatch.patch) | Handles fixed-size raw snapshot copies directly in the deserialization loop, avoiding generic dispatch. | [Confirmation](evidence/snapshot-dispatch-confirm/report.json.gz), eval **1.01236× [1.00608, 1.01978]**, n=250; ESM did not establish a win. | V8 implementation change; snapshot format and traced path unchanged. Slot-width and pointer-compression handling require care. Physical debug/pointer-compressed builds remain unvalidated. |
| [07 — Lazy timezone framework](patches/07-deps-cctz-lazy-corefoundation.patch) | Loads CoreFoundation when CCTZ first needs the system timezone instead of linking it eagerly. | **Grouped with 08:** [framework confirmation](evidence/lazy-frameworks-confirm/report.json.gz), eval **1.07435× [1.06972, 1.07913]**, n=250. No isolated 07 estimate. | Apple-specific CCTZ/Abseil code carried through V8. Moves framework load cost to first timezone use; retains the loaded image for process lifetime. Missing framework/symbol lookup aborts. |
| [08 — Lazy certificate frameworks](patches/08-crypto-lazy-darwin-frameworks.patch) | Loads Security/CoreFoundation when system certificates are requested and removes Node's eager framework links. | Same [07+08 measurement](evidence/lazy-frameworks-confirm/report.json.gz), not another independent gain. Patch 07 is also needed to remove the eager CoreFoundation dependency. | Apple-specific Node crypto/build change. First system-CA use pays the deferred load cost. Dynamic function/constant bindings need maintenance; local timezone, certificate, worker and profiler checks do not cover every Apple OS or Instruments template. |
| [09 — Private bundled ICU](patches/09-build-private-bundled-icu.patch) | Hides bundled ICU implementation symbols from the executable's dynamic exports. | [ICU without WPD](evidence/icu-no-wpd-confirm/report.json.gz), CJS **1.02153× [1.00719, 1.03147]**, n=350. ESM/eval intervals include 1. This isolates ICU more closely than the older ICU+WPD experiment. | Static Darwin builds using generic bundled ICU; shared/system ICU unchanged. Deliberately removes [9,313 private ICU exports](evidence/icu-export-audit.json), potentially breaking addons that import them. |
| [10 — Compact encoding data](patches/10-lib-compact-encoding-tables.patch) | Stores 27 single-byte encoding maps as compact UTF-16 strings rather than numeric delta arrays, shrinking snapshot data. Decoder tables remain separate and the module stays preloaded. | [Confirmation](evidence/encoding-compact-eager-confirm/report.json.gz), CJS **1.00740× [1.00347, 1.01155]**, ESM **1.00696× [1.00182, 1.01228]**, n=350. Eval and Windows-1252 first use establish neither gain nor regression. | Platform-independent JavaScript/data change. Encoded tables are less readable; edits must preserve every mapping, unmapped byte and streaming/fatal behavior. |
| [11 — OpenSSL cleanup registration](patches/11-crypto-darwin-exit-registration.patch) | Registers OpenSSL's cleanup callback with its known Darwin image, avoiding the loader lookup performed by ordinary exit registration. Cleanup still runs. | **Not independently isolated.** The older [Node+OpenSSL registration experiment](evidence/atexit-ablation/report.json.gz) measured eval **1.08866× [1.07518, 1.09767]**, n=80. A later [Node-only ablation](evidence/curated-node-atexit-isolation/report.json.gz) found no gain; subtraction would not yield an OpenSSL estimate. | Darwin OpenSSL dependency patch. Equivalence relies on a same-image wrapper and the same DSO handle, not arbitrary foreign callbacks. Requires unload/exit-order checks and maintenance across OpenSSL updates. |
| [12 — Small-factor screening](patches/12-deps-rapidhash-small-factor-screen.patch) | Rejects obvious composite hash-secret candidates using small divisors before expensive primality testing. | [Confirmation](evidence/small-factors-confirm/report.json.gz), eval **1.00593× [1.00192, 1.01222]**, n=250. A small gain; CJS/ESM also improved in this run. | Platform-independent Rapidhash change; declared prerequisite 03. The guard must preserve small primes and exact generated secrets. |
| [13 — Montgomery arithmetic](patches/13-deps-rapidhash-montgomery.patch) | Replaces repeated wide division during primality-test exponentiation with Montgomery modular multiplication. | [Confirmation](evidence/montgomery-confirm/report.json.gz), eval **1.00784× [1.00192, 1.01310]**, worker **1.00412× [1.00030, 1.00622]**, n=400. **No established CJS/ESM win**; both intervals include 1. | Native 128-bit implementation, portable fallback retained; prerequisites 03+12. | [14 — Trained code order](patches/14-build-darwin-trained-order.patch) | Adds an optional linker order file to place CLI code in training-observed execution order. | [Same-object layout repeat](evidence/temporal-layout-fork-all-repeat/report.json.gz), CJS **1.01293× [1.00808, 1.01589]**, eval **1.00842× [1.00471, 1.01107]**, n=500. Measures the trained order, not the mere availability of the option. | Static Darwin Ninja CLI link only; build-context prerequisites 01+02. Needs matching training/toolchain provenance and verified symbol placement. Another binary's order file is not a portable default. |
| [15 — Whole-program virtual calls](patches/15-build-bounded-whole-program-vtables.patch) | Optimizes virtual calls whose implementations are confined to the executable, while marking public extension interfaces as open to external implementations. | [Historical repeat](evidence/whole-program-vtables-repeat/report.json.gz), ESM **1.00361× [1.00044, 1.00818]**, n=500; CJS/eval did not establish wins. Missing public annotations can cause incorrect addon dispatch, demonstrated by the [compiler control](evidence/wpd-control/result.json). New public polymorphic interfaces require ongoing review. |

## Validation limits

The [final local gate](evidence/local-gate.json) passed the 6,173-case Node selection with 370 skips, 11 TODO-tagged cases and no unexpected failures. The [validation overview](README.md#validation) records the remaining boundaries; these local results do not establish universal compatibility or Linux/Windows performance.

## Separate entropy proposal

Node PR [#65796](https://github.com/nodejs/node/pull/65796) changes V8's entropy source to the OS CSPRNG and defers ordinary OpenSSL DRBG initialization. It is **not one of these 15 patches** and is distinct from patch 11's cleanup registration: the frozen fork still performs the startup seeding check and uses OpenSSL for V8 entropy in [Node initialization](https://github.com/nodejs/node/blob/8af75451e9041cd6058080ad3d4a65546797b418/src/node.cc). No marginal measurement of that PR on this fork is included.
